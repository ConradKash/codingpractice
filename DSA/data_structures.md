## Linear Data Structures

### Arraya

- An array is a collection of finite, homogeneous and ordered data elements

#### Characteristics

    Size - This is the size of the array
    Type - This is the data domain too store
    Index - This is a subscript that identifies a particular element
    Base - This is the memory adress of the first element in the array
    Index Range - this is range of available indexes
    Continuous memory allocation - This states that it stores continuously in memory

#### Advantages of arrays

    - Storing multiple values compared to scalar data types
    - Fast access especially when using indexes
    - Easy to use simce they are straigt forward and no pointers
    - Efficient memory usage since they are storedi in nearly close memory stores so they can easily be referenced
    - better cache performance because of continuous memory allocation.

#### Disadvatanges
    - No dynamic sizing
    - It is only accepts one data type at a go
    - fized size
    - inserting and deleting overhead

#### Applications of arrays
    - Sorting and searches
    - Storing similar scalar data 
    - Implemeting similar data structures
    - Arrays are commonly used in relational databases
