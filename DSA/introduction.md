## Inroduction.

- An algorithm is a sequence of finite unique computational steps that turn input into output

#### Characteristics of an algorithm

    - input
    - output
    - finite
    - unique
    - effectiveness

- A data structure is the definition of a domain, a function and the rules to implement the functions of given data.

- A datatype referss to the type of value that a variable in a programming language holds

#### Characteristics of data structures
    - Domain (Range of data)
    - Axioms (Rules to use operations)
    - Functions (Operations on data)
